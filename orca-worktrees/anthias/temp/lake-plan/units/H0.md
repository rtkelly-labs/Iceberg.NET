# H0: Install the Mend Renovate GitHub App

**Executor:** human · **Wave:** 1 · **Depends on:** nothing

## Goal

Install Renovate on the rtkelly-labs organisation (and rtkelly13 if wanted).

## Where

- Repository: (org)
- Base: `origin/main`

## Steps

1. Install from https://github.com/apps/renovate/installations/new on `rtkelly-labs` (all repositories).
2. Check that `ci` is a required status check on `main` in Iceberg.NET, so auto-merged patches wait for CI.
3. After U01c merges, the first Dependency Dashboard issue appears; the first batch arrives on the Monday schedule.

## Done when

- The app is listed under the organisation's installed GitHub Apps.
