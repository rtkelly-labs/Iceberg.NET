## Steps

1. `rig estate rename-repo <old> <new>` prints a plan; `--apply` executes it. The plan covers:
2.   1. `config/managed-projects.json`: the entry's `name`, `repo` URL, and (optionally, `--packages old=new` mappings) its `packages[]`.
3.   2. The main clone: `git remote set-url origin <new>`, then optionally move the directory (`~/code/rtkelly-labs/Iceberg.NET` → `…/Lake.NET`).
4.   3. Worktrees: moving the main clone breaks every linked worktree's `.git` file. Run `git worktree repair <each path>` from the moved clone; for Orca worktrees under `~/orca/workspaces/<old>/`, list them with `orca worktree list --repo name:<old> --json`.
5.   4. Orca: re-register the moved repo path and display name (`orca repo` commands, or `workspace orca sync`); keep existing worktrees working.
6.   5. Checks after apply: `git fetch` works in the clone and every worktree; `rig estate audit` shows the repo once; `workspace orca doctor` passes.
7. Refuse to apply while any worktree has uncommitted changes, unless `--force`, matching `estate tidy`'s safety rules.
8. Tests on temporary git repositories with worktrees (no network, no Orca: the Orca step is behind an interface with a fake).
