## Steps

1. For each package entry (registry, name, manifest, workflow): latest version on the registry (NuGet: `https://api.nuget.org/v3-flatcontainer/<id>/index.json`; also listed/deprecated state from the registration API), the latest git tag that matches it (supports both `v<version>` and `<PackageId>/v<version>` tag styles), and whether the repo's changelog has entries under `[Unreleased]` (root `CHANGELOG.md` or a per-package one next to the project).
2. Flag: unreleased changes; a tag with no registry version; a registry version with no tag; deprecated or unlisted packages; projects whose packages share a version family but drifted apart.
3. Output a table like `estate audit`, plus `--json`. Read-only, no `--apply`.
4. Tests with recorded registry responses (no network in tests).
