## Steps

1. Check how Renovate resolves an organisation's default preset (`rtkelly-labs/renovate-config` vs the `.github` repository) for the hosted app; use whichever needs no new repository.
2. Generic rules go in the preset: schedule, limits, `minimumReleaseAge`, semantic commits, pinned Action digests, major-update approval, patch auto-merge for nuget and github-actions, the .NET 10 / AWS SDK / test-tooling groups.
3. Iceberg-specific rules stay in Iceberg.NET (oracles, Spark, Parquet, the emulation regexes); a follow-up PR there replaces the generic block with `extends: ['github>rtkelly-labs/…']`.
4. Validate both files with `renovate-config-validator`, and run Iceberg.NET's local dry run (docs/dependencies.md) to confirm the same dependencies and groups are found.

## Done when

- The dry-run report lists the same dependencies and groups before and after.
