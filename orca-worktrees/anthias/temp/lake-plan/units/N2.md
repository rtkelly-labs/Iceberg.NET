## Steps

1. Add `Microsoft.CodeAnalysis.PublicApiAnalyzers` to every packable project with the whole current surface in `PublicAPI.Unshipped.txt` (generate with the RS0016 code fix or `dotnet format analyzers --diagnostics RS0016`). Build must pass with warnings as errors.
2. Split the root `CHANGELOG.md`: a `CHANGELOG.md` per packable project with an empty `[Unreleased]`; the root keeps repository-level changes and a table of packages.
3. `<VersionPrefix>` per project (or `version.props`), and release-please manifest config (`release-please-config.json`, `.release-please-manifest.json`) with `linked-versions` per family (D12) and `extra-files` for the version.
4. Port `pr-title.yml` from Parquet.SourceGenerator (pin actions to SHAs with version comments).
5. `scripts/ReleasePlan.cs`: fail when `PublicAPI.Unshipped.txt` has `*REMOVED*` entries but the PR title isn't breaking (`!`); list dependents a breaking change cascades to. Run it in CI on PRs.
6. `release.yml`: release per package in dependency order with tags `<PackageId>/v<version>`, keeping the existing safeguards (main only, no re-release, CI-green commit). Dry run with `workflow_dispatch` dry-run mode.

## Done when

- Build passes; RS0016/RS0017 fire when a public member is added without updating Unshipped (show it in the PR with a throwaway commit, then drop it).
- `ReleasePlan.cs` passes on this PR and fails on a crafted breaking change.
- A release dry run plans every package at `0.0.1-alpha.1` (D6).
