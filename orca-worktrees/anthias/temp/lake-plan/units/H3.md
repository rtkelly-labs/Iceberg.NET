# H3: First Lake.* release and retiring Iceberg.Net.*

**Executor:** human · **Wave:** 5 · **Depends on:** N2, H2, R5

## Goal

Publish every `Lake.*` package at `0.0.1-alpha.1`, then retire the old IDs.

## Where

- Repository: Lake.NET
- Base: `origin/main`

## Steps

1. Merge the release PR that N2's tooling produces; the release workflow publishes per package.
2. Request the `Lake.` ID prefix reservation on nuget.org (needs a published package first).
3. Run `rig estate packages retire --map …` (R5): deprecate each `Iceberg.Net.*` `0.0.1-alpha.1` as Legacy with its `Lake.*` alternative, then unlist.
4. `rig estate packages` shows every Lake.* package released and every Iceberg.Net.* retired.

## Done when

- `rig estate packages` is clean.
